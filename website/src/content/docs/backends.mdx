## What this part does

Backends translate a model family's concrete module layout into the small set of
operations the routing framework needs. They verify the family contract,
discover decoder MLPs in stable order, replace selected MLP references safely,
and report exactly which layers were converted.

<IntegrationBadge status="Integrated" />

Qwen3 is the validated MLP-conversion backend. Routing decisions, expert
weights, calibration, package lifecycle, and sparse dispatch remain outside
this layer so another model family can be added without changing those
strategies.

`NeedleBranchBackend` implements a separate shared-prefix contract for Needle
3. See [Needle branches](/docs/needle-branches/) for suffix ownership, isolated
training, cached decoding, and native export. It is not selected through
`AnchoredMoEConfig` or the Hugging Face model façade.

## Where it fits

The backend sits between configuration and the model-neutral `RoutedMLP`:

1. `AnchoredMoEConfig` names the backend and selects decoder layers;
2. `AnchoredMoEForCausalLM` resolves or receives a matching backend;
3. the backend validates the live model before structural mutation;
4. it discovers replaceable MLPs and resolves the selected layer indices;
5. it freezes the incumbent model and moves each selected MLP into a
   `RoutedMLP`;
6. the native model continues to own attention, forward, and generation.

The backend does not choose an expert or compute a router score. A newly
converted wrapper starts in `forced_anchor` mode and calls the same original
MLP once.

### The model-family contract

Every `ModelBackend` implementation owns four operations:

| Operation | Responsibility | Failure boundary |
|---|---|---|
| `supports_model()` | Confirm the declared family and required decoder structure. | Returns `false` for an incompatible or incomplete model. |
| `iter_mlp_references()` | Yield replaceable MLP references in decoder order. | Rejects a model that does not satisfy the exact family contract. |
| `replace_mlp()` | Replace the module originally observed at one location. | Rejects a stale reference or a non-module replacement. |
| `convert()` | Freeze the model, wrap selected MLPs, and return a deterministic report. | Rejects a mismatched backend or an already-routed selected layer. |

`MLPReference` records the zero-based layer index, owning module, attribute
name, and module observed during discovery. `ConversionReport` records the
backend name, total decoder depth, and ordered converted indices. Neither type
contains routing policy or expert state.

## How it works

### Validate the Qwen3 structure

`Qwen3Backend` requires `model.config.model_type == "qwen3"`. It supports the
decoder path used by `Qwen3ForCausalLM` (`model.model.layers`) and the direct
path used by `Qwen3Model` (`model.layers`). The resolved layers must be an
ordered module sequence, and every layer must expose an MLP module.

These checks are deliberately structural. A model that happens to have a
similar attribute name is not accepted unless it also declares the supported
family contract.

### Discover before changing anything

The adapter snapshots an `MLPReference` for every decoder layer, then asks the
configuration to resolve the requested indices against the discovered depth.
Explicit selections are already sorted and deterministic by this point.

Replacement succeeds only if the layer still owns the exact module captured
during discovery. If another operation changed that attribute, conversion
raises instead of overwriting the newer state.

### Freeze and wrap selected MLPs

Before replacement, the backend checks every selected reference for an existing
`RoutedMLP`. Conversion is intentionally not idempotent: a second conversion
would obscure ownership and create nested routing state, so it is rejected.

After all prechecks pass, the complete model is frozen. Only selected
`layer.mlp` attributes are replaced, and each wrapper owns the original MLP
object as `anchor_mlp`. Unselected MLPs, attention, embeddings, normalization,
and the language-model head retain their module objects and parameter values.

## Minimal usage

Convert selected layers of an already loaded Qwen3 causal language model:

```python
from anchored_moe import AnchoredMoEConfig
from anchored_moe.backends import Qwen3Backend

report = Qwen3Backend().convert(
    model,
    AnchoredMoEConfig(converted_layers=[1, 3]),
)

assert report.converted_layers == (1, 3)
```

`model` must satisfy the supported Qwen3 contract. After this call it is frozen,
layers 1 and 3 contain routed wrappers, and both wrappers remain in exact
forced-anchor mode.

## Current limitations

- Qwen3 is the only implemented model-family adapter.
- The validated decoder paths cover ordinary Transformers
  `Qwen3ForCausalLM` and `Qwen3Model` objects, not arbitrary wrappers with
  different ownership paths.
- Production remote checkpoints, optimized kernels, quantized layouts,
  multiple devices, and distributed execution require separate validation.
- Conversion is deliberately one-way for a live model; calling it twice is an
  error rather than a no-op.
- Backend conversion creates forced-anchor wrappers only. Package
  synchronization and advanced routing modes belong to modeling, registry, and
  inference layers.
- Exact equality is established on the deterministic CPU test path. Other
  runtimes must declare and test their own tolerances.

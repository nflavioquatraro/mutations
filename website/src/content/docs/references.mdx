## What this index contains

This is the canonical bibliography for research ideas and reproducibility
standards discussed in the Mutations documentation. Each entry links directly
to its primary source, explains what the source motivates, and states where
the repository intentionally differs.

Routine framework API documentation remains on the page where that API is
used. This keeps the index focused on conceptual and algorithmic provenance
rather than turning it into a dependency directory.

## Current limitations

This is a curated implementation bibliography, not an exhaustive survey of
Mixture-of-Experts research. A paper appears here only when the repository
documentation identifies a concrete implementation influence. Inclusion does
not mean Mutations reproduces the paper's architecture, training procedure, or
reported results; those boundaries are stated on every entry.
